# skillpaccc

Personal skill collection.

## Storage convention

All reusable skills are stored at:

```text
skills/<skill-name>/SKILL.md
```

Current skills:

- `skills/url-knowledge-capture/SKILL.md`
- `skills/opus55-creative-video-reference/SKILL.md`

## Operating rule

When a new reusable workflow or skill is created:

1. save/update the working copy in the local `/SKILLS/<skill-name>/SKILL.md` collection;
2. save the GitHub copy in this repository under `skills/<skill-name>/SKILL.md`;
3. update an existing skill instead of creating a duplicate when the workflow already exists;
4. keep source-specific facts and reusable operating rules separated;
5. preserve provenance, verification state, and failure behavior inside skills that depend on external sources.
